# Predição de Aprovação Escolar

Este projeto tem como objetivo prever a aprovação de estudantes do ensino médio utilizando técnicas de análise de dados e machine learning, incluindo redes neurais.

## Como rodar o projeto

1. Instale as dependências:
   ```
   pip install -r requirements.txt
   ```
2. Execute o Jupyter Notebook:
   ```
   python -m notebook
   ```
3. Abra o notebook principal (ex: `analise_modelagem_unica.ipynb` ou `Rede Neural.ipynb`) e execute célula por célula.

## Estrutura do Projeto
- `dados/raw/`: Dados originais (student-mat.csv, student-por.csv)
- `requirements.txt`: Dependências do projeto
- `analise_modelagem_unica.ipynb` ou `Rede Neural.ipynb`: Notebook principal
- `documentacao.txt`: Documentação detalhada do projeto

## Funcionalidades
- Análise exploratória dos dados (EDA)
- Tratamento e preparação dos dados
- Modelos de classificação e regressão (incluindo redes neurais)
- Avaliação com métricas apropriadas
- Comparação entre modelos
- Relatório final com conclusões

## Observações
- Os dados devem estar na pasta `dados/raw/`.
- O projeto pode ser executado no Jupyter ou Google Colab.
